Proposed · one family

What changes

One family. Five cards, three vocabularies today (ncm-cc, ncm-ice-card, ncm-payload-card) plus two JS-built ones (ncm-wcard, ncm-netcard). Proposed: every card is ncm-cc with a tone modifier, same header / body / footer anatomy, so the eye learns one card.

Legible. Body text goes from 11px mono to 13px in the reader's body font (the message was never a terminal readout). Labels 8px → 9.5px, badges 9px → 10.5px, footer 9px → 10px, and the near-black greys lift to the module's text tokens.

Themeable. Cards use var(--ncm-*, #fallback). The chat log is body-mounted, but the player ThemeService writes to :root, so a player's own palette and fonts reach their chat for the first time. Today's cards are literal hex.

Shared message. Sender and recipient become avatar + name + address (the directory-first resolver, the same one the inbox uses). Subject is the headline. The whole body renders in the body font with its formatting (bold, lists, quotes) — the fix that already landed, dressed properly. "via GM" / "via V" in the header.

Roll card. The three cells and the total bar stay, bigger. The verdict moves INTO the total bar (19 vs DV 15 · SUCCESS) instead of a second badge in the header.

ICE. Portrait, name, class, then the damage block; the LETHAL chip and the dice tray go (the formula already says what rolled).

Dead weight. network-event.hbs and payload-executed.hbs have no caller — nothing renders them — but they are preloaded on every world load. Delete both.

Add contact. Each From/To row can carry an Add chip. Chat HTML is one document for everyone, so the chip is decided per CLIENT when the message renders (Foundry's renderChatMessage hook): shown only when that person is not in your contacts, never for yourself, a masked anonymous sender, or a send-only address; already-a-contact rows show a quiet check. Clicking adds them the same way the inbox's Add does (portrait, actor link, directory id).

Whisper strip stays only on cards that are whispers (malware analysis, GM whispers). It was the "GM Intercept" lie on the shared card.
