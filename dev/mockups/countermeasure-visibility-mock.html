1 · The network login dialog — what the character can tell

The same CorpNet node (Black ICE "Hellhound", 3d6 to HP, failures traced, 3 attempts, bypass DV 17). The ways in are always shown — anyone can see there's a password box. What's guarding it is not.

2 · The scan, and a roll with the DV hidden

The scan is an ordinary roll through the shared Roll Reveal. With "Hide the DV" on, the line on the bar has no number until the verdict lands — then the DV appears, here and on the chat card. You learn how hard it was by trying.

3 · Admin → Security → Countermeasure Visibility (the world default)

Off by default ("Open" = today). The expert rule is the same builder as Operator Access, so a GM who has written one already knows this one.

4 · Per-object override (Network Manager → Security; the same row on shards, terminal accounts, encrypted contacts and messages)

"This one hides its Black ICE well" — Concealed with its own scan DV. "The corp wants you to see the dogs" — Always visible.
