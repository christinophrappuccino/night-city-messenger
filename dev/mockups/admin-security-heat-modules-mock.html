Admin → Security → Heat — two module takes

Same data in both: heat per character × object (0–100, drains ~5/hour of game time; cold <25 · warm 25–49 · hot 50–79 · burned 80+), plus two running trace countdowns. The demo drains heat a point every few seconds and ticks the clocks so you can see motion. Click things.

Version A — thermometers

One tall gauge per character showing their hottest object. The tube is banded cold → burned, the fill slowly drops as heat decays, and small ticks on the side mark each object's heat so you can see when one character is warm in several places. A red clock ring above a gauge means a trace is closing in on that character, shrinking as time runs out. Click a gauge to open that character on the right: every object with its own bar, the countdown, and Adjust / Clear / Escalate (Lock out, Black ICE, Countdown).

Version B — heat grid

A table you read at a glance: one row per character, one column per object, each cell shaded by tier with the number in it (a blank dashed cell = no heat there). The last column is the trace fuse — a line burning down from right to left with the time left and who is closing in. Burned cells glow. Click a cell to get one action strip underneath for exactly that character × object; click a column header to highlight one object across everyone, or a name to highlight a row. Best when several characters are hitting the same targets.
