1 — DELIVERY JOURNEY  ·  Messages → All mail → the open message

A track under the From / To / When block: Sent → Network → Delivered → Read → Replied. Each stop has its time; the line is green as far as the message got. Where it stopped, the stop turns amber (waiting) or red (failed) and a line underneath says why in plain words, with the button that fixes it. A group send swaps the big track for one small track per recipient.

2 — GETTING THE TABLE READY  ·  Overview, at the top

A checklist that knows the world: each line checks something real and says what's missing in words ("Rache has no address"). The button on each line opens the exact place that fixes it. Optional items are grey and never block the ring. Once it's all done the card folds to one line, and "Hide" removes it until something breaks again.

3 — TERMINAL ACCESS PATH  ·  Terminals → detail → Accounts

Each account gets the breach path: reach (the network a player must be on) → uplink (the machine's own connection) → ways in (password / skill / key item, as OR or AND) → mailbox. Green as far as someone's got; a locked-out character shows red at the step that stopped them, with their name and the time left. Click a step to force it open or shut for everyone; the footer has the per-character actions.
