RECORDS REDESIGN — typed-field dossiers + card builder

A record = a subject (portrait / name / status / flag) + a flexible set of typed fields you add from a palette. A DB-kind quick-start (Personnel / Criminal / Medical / Vehicle / Contacts / Employee) seeds the right field chips, then you can add/remove any field on any record. Old records auto-migrate (role/org/address become fields). Dates open the CyberTimePicker; threat is a clickable 1–4 meter; address can link a scene (like LOCATION). The viewer stays a searchable database — every field renders with its own icon.
