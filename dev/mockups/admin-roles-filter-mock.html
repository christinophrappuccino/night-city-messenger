A — THE ROLE MANAGER  ·  Admin → Contacts → edit a contact → Role → Manage roles…

One window that never closes on you. Left: every role — search, chips for Built-in / Custom / In use, how many contacts use each. Right: the selected role. A custom role is edited right there — name, colour (the theme palette, or any colour), icon (search the grid), and a preview the way it shows on a contact and as a Directory group. A built-in role can't be changed, but you see who uses it. New role starts a blank one. Delete says how many contacts lose it first.

B — DIRECTORY FILTER  ·  Admin → Contacts → Directory

A Filter button beside Group and Sort opens a picker with three tabs — Roles, Organizations, Trust — each with search and counts. Tick several (Fixers + Execs + Medtechs) or use only on a row. Active filters sit under the toolbar as chips in their colour; ✕ removes one; the list narrows as you go. Same picker the Messages filter uses.
