What changed

Built for many terminals. One scrolling list instead of 10 per page, grouped under sticky headers you can fold. Group by location (default), the scene it's pinned on, organisation, the item's folder, or preset.

Filters answer real questions: who's logged in, which ones need you (a lockout, an armed plant, heat, a GM unlock left on), which aren't pinned anywhere, and which are on the scene you're viewing. Each shows its count.

Rows are dense: name, where it is, accounts, and live state (● online, ⚠ needs you, 🔓 unlocked).

The detail leads with what's happening now, then setup in two short columns, the accounts as a table (who can get in and how), and recent logins.

Open and Configure stay up top; Force-unlock, Reset, Export, Place on scene and Remove go in the ⋯ menu.

Select ticks rows for Reset, Export or Remove in one go — e.g. reset every terminal in a building before a session.
