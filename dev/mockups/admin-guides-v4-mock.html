1 — THE DELIVERY LINE  ·  Messages → All mail → the open message

(Drawn at the real widths now: reading pane 475px, Configure Terminal 668px, Terminals detail 486px.) One line under From / To / When that answers it. Quiet green when all is well; amber or red when not. Click it and it opens in place: what happened, why, what the player saw, what happens next by itself — with the fixes as buttons. Use a fix and the line updates. Try each one.

3a — LOCK ODDS IN THE ACCOUNT EDITOR  ·  Configure Terminal → Accounts → an account → Login & security

Where the lock is set. Beside the ways in, a "How hard is this for your party" panel reads each character's sheet and moves as you edit: step the DV, switch skill rolls on and off, require all methods. The verdict underneath says what that means in a sentence.

3b — ACCOUNT STATUS IN PLAY  ·  Admin → Terminals → detail → Accounts

During the session: each account lists the party with what's true right now — in (since when), locked out (with a live clock), tries left, or can't even see it (and why). Each row has the one action you'd want. Click them.
