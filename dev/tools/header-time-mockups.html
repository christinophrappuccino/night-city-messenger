Night City Messenger — Inbox Header · Time Readout

Four ways to make the header clock easier to read, shown in the real header layout. The Current version is first for comparison. Use the swatches to preview how each option follows the active theme accent (the time color is theme-aware in every option; location keeps its gold identity).

Theme accent:
Current— what's there now
Value is 10px mono in a soft purple at ~5% bg; the "TIME" label is 5px / 45% opacity (basically invisible). Same weight as Location, and it sits next to the bright network pill.
Option 1 — Bigger & brighter clocksmallest change, big win
Enlarged ~17px digits, clock icon replaces the tiny label, high-contrast accent color, solid chip. Time clearly outranks the (smaller) Location chip.
Option 2 — Neon terminal clockcyberpunk flourish
Oversized ~22px digits with a neon glow and a softly blinking colon; Location demoted to a quiet inline tag. Most eye-catching, leans into the aesthetic.
Option 3 — Icon + inline (no labels)cleanest / compact
Drops the labels and chip boxes entirely: clock icon + ~15px value, pin icon + location. Brighter time for hierarchy. Saves the most header width.
Option 4 — Unified HUD stripsingle status module
Both readouts in one bordered bar — time large/bright on the left, location muted on the right, divider between. Reads as one cohesive widget.
